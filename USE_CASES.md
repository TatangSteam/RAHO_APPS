# Use Cases - RAHO ERP Management System

Last updated: 6 Juli 2026

| UC ID | Actor | Use Case | Trigger | Main Flow | Alternate Flow |
| --- | --- | --- | --- | --- | --- |
| UC-001 | User | Login ke sistem | User membuka halaman login dan memasukkan kredensial. | 1. User mengisi email dan password. 2. Sistem memvalidasi kredensial. 3. Sistem membuat access token/session. 4. Sistem mengambil profil, role, dan branch access. 5. User diarahkan ke dashboard sesuai role. | Jika kredensial salah, sistem menampilkan error. Jika rate limit tercapai, login ditolak sementara. Jika user inactive, sistem menolak login. |
| UC-002 | User | Logout dari sistem | User memilih tombol logout. | 1. User menekan logout. 2. Sistem mengakhiri session/token. 3. Sistem mencatat audit log. 4. User diarahkan ke login. | Jika token sudah expired, user tetap diarahkan ke login. |
| UC-003 | User | Refresh session | Token hampir kedaluwarsa saat user masih aktif. | 1. Frontend meminta refresh token. 2. Sistem memvalidasi refresh token. 3. | UC-004 | User | Melihat profil user aktif | User membuka menu profil atau aplikasi memuat data sesi. | 1. Sistem membaca token. 2. Sistem mengambil data user aktif. 3. Sistem mengembalikan profil, role, dan branch access. | Jika token tidak valid, sistem mengembalikan unauthorized. |
| UC-005 | User | Reset password | User lupa password dan meminta reset. | 1. User memasukkan email. 2. Sistem membuat token reset. 3. Sistem mengirim instruksi reset. 4. User membuka link reset. 5. User membuat password baru. | Jika email tidak terdaftar, sistem menampilkan respons aman. Jika token expired, user harus request ulang. |
| UC-006 | Super Admin | Membuat user/staff | Super admin membuka menu user dan memilih tambah user. | 1. Super admin mengisi data user. 2. Super admin memilih role dan branch. 3. Jika branch tidak valid, sistem meminta koreksi. |
| UC-007 | Super Admin/Admin Cabang | Mengubah data staff | Admin membuka detail staff dan menyimpan perubahan. | 1. Admin membuka staff. 2. Admin mengubah data profil, role, status, atau cabang. 3. | UC-010 | Super Admin/Admin Manager | Melihat performa staff | Admin membuka menu staff performance. | 1. Admin memilih periode dan cabang. 2. Sistem mengambil aktivitas staff. 3. Sistem menyimpan perubahan dan audit log. | Jika field tidak valid, sistem menolak. Jika staff tidak punya akses cabang member, sistem menolak. |
| UC-019 | Staff | Upload dokumen member | Member menyerahkan dokumen atau consent form. | 1. Staff membuka tab dokumen. 2. Staff memilih file. 3. Sistem memvalidasi tipe/ukuran file. 4.
